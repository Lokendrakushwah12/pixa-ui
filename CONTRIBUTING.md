# Contributing to Pixa UI

We welcome contributions to our project! Please follow these steps to contribute:

## Getting Started

1. Fork the repository on GitHub.
2. Clone your forked repository to your local machine:
   ```bash
   git clone https://github.com/your-username/pixa-ui.git
   ```
3. Navigate to the project directory:
   ```bash
   cd pixa-ui
   ```

## Making Changes

4. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b your-branch-name
   ```
5. Install the project dependencies:
   ```bash
   npm install
   ```
6. Make your changes to the codebase.
7. Build the project:
   ```bash
   npm build
   ```
8. Test the application to ensure your changes work as expected.

## Submitting Changes

9. Commit your changes:
   ```bash
   git commit -m "Your commit message"
   ```
10. Push your changes to your fork:
    ```bash
    git push origin your-branch-name
    ```
11. Open a pull request on the original repository.

## Additional Information

- Before submitting a pull request, please ensure your code follows our coding standards
- Write meaningful commit messages
- Update documentation if necessary

Thank you for contributing to our project! If you have any questions, feel free to open an issue or reach out to me.
